🚀 Comment mettre à jour la plateforme

Ce guide s'adresse à toute personne de la MRC. Aucune connaissance technique requise.

1
Cliquer « ✏️ Mettre à jour »

Dans la barre en haut ou le menu gauche. Entrer le mot de passe.

2
Modifier les données

Trimestre, KPIs, emplois par secteur, emplois des entreprises. Cliquer ✅ Enregistrer.

3
Exporter data.json

Cliquer 💾 Exporter data.json. Le fichier se télécharge sur votre ordinateur.

4
Remplacer le fichier sur le serveur

Option A (GitHub) : ouvrir data.json → ✏️ → effacer tout → coller → Commit changes.
Option B (hébergement) : uploader le nouveau data.json dans le même dossier que index.html.

5
Vérifier (attendre ~2 min)

Recharger la page. Tout le monde voit les nouvelles données automatiquement.

💡 Copier-coller rapide

Ouvrez le fichier téléchargé avec Notepad → Ctrl+A → Ctrl+C → collez dans GitHub.

⚠️ Ne modifiez jamais index.html. Seul data.json doit être mis à jour pour les données.
