🚀 Déployer sur GitHub Pages

GitHub Pages héberge gratuitement votre tableau de bord. Voici comment mettre en ligne et comment mettre à jour les données :

1
Créer un compte GitHub gratuit

Allez sur github.com → "Sign up". Un compte suffit pour toute l'équipe.

2
Créer un nouveau dépôt public

Cliquez "New repository" → Nommez-le granit-dashboard → Cochez "Public" → "Create repository".

3
Téléverser les 2 fichiers

Cliquez "uploading an existing file" → glissez index.html et data.json → "Commit changes".

4
Activer GitHub Pages

Onglet "Settings" → section "Pages" → Source : "Deploy from a branch" → Branch : main → Dossier : / (root) → "Save".

5
Votre URL est prête!

Dans ~2 minutes : https://[votre-compte].github.io/granit-dashboard — partagez ce lien avec toute l'équipe.

🔄 Workflow mise à jour trimestrielle
1. Ouvrez le tableau de bord → ✏️ Mettre à jour → modifiez les données
2. 💾 Exporter data.json → sauvegardez le fichier
3. Sur GitHub, ouvrez data.json → cliquez ✏️ → collez le nouveau contenu → "Commit"
4. Tout le monde voit les nouvelles données en moins de 2 minutes ✅
