✏️ Mise à jour

🚀 Comment mettre à jour la plateforme

Ce guide s'adresse à toute personne de la MRC qui doit mettre à jour les données du tableau de bord. Aucune connaissance technique requise.

📋 Mise à jour via le tableau de bord (recommandé)
1
Ouvrir le tableau de bord et cliquer « Mettre à jour »

Cliquez sur ✏️ Mettre à jour dans la barre en haut ou dans le menu gauche. Entrez le mot de passe administrateur.

2
Modifier les données dans les formulaires

Changez le trimestre, les KPIs, les emplois par secteur, les notes. Pour les entreprises et collaborations, utilisez l'onglet correspondant. Cliquez ✅ Enregistrer.

3
Exporter le fichier data.json

Cliquez 💾 Exporter data.json dans le menu gauche. Un fichier data.json se télécharge automatiquement sur votre ordinateur.

4
Mettre à jour le fichier sur GitHub

Allez sur github.com → votre dépôt → cliquez sur data.json → cliquez l'icône crayon ✏️ → Effacez tout le contenu → collez le contenu du nouveau fichier → cliquez Commit changes.

5
Vérifier en ligne (2 minutes d'attente)

Attendez ~2 minutes puis rechargez la page du tableau de bord. Tout le monde verra les nouvelles données automatiquement.

💡 Astuce : copier-coller rapide dans GitHub

Dans votre fichier data.json téléchargé → ouvrez-le avec Notepad (clic droit → Ouvrir avec → Bloc-notes) → Ctrl+A pour tout sélectionner → Ctrl+C pour copier → collez dans GitHub.

➕ Ajouter une nouvelle entreprise
A
Via le panel admin → onglet Entreprises

Dans ✏️ Mettre à jour, faites défiler jusqu'à la section 🏢 Entreprises. Modifiez une fiche « À compléter » ou ajoutez une ligne. Exportez ensuite le data.json et commitez sur GitHub.

🔑 Accès et mots de passe
B
Mot de passe du tableau de bord

Modifiable dans ✏️ Mettre à jour → section 🔐 Changer le mot de passe. Mot de passe par défaut : granit2025.

C
Accès GitHub — plusieurs personnes

Sur GitHub, allez dans Settings → Collaborators → invitez les membres de l'équipe par leur courriel. Ils pourront éditer data.json directement en ligne.

⚠️ Important : Ne modifiez jamais index.html — c'est le code de l'application. Seul data.json doit être mis à jour pour les données.
